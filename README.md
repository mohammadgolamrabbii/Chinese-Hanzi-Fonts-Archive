## 🏛️ স্থাপত্য কাঠামো ও শৈলী বিন্যাস (Canonical Architecture)

চীনা হানজি (Simplified 简体 & Traditional 繁體) টাইপোগ্রাফির সমৃদ্ধ ২০০০ বছরের ঐতিহ্য ও আধুনিক স্ক্রিন ইউজার ইন্টারফেসের চাহিদা অনুযায়ী এই ভল্টটিকে ৬টি ক্যানোনিকাল ক্যাটাগরিতে বিভক্ত করা হয়েছে:

| ডিরেক্টরি | চীনা নাম | টাইপোগ্রাফিক বৈশিষ্ট্য | প্রধান পরিবারসমূহ |
| :--- | :--- | :--- | :--- |
| **`01_Song_Ming_Classical_Serif`** | **宋体 / 明体** | হাই-কনট্রাস্ট হরিজন্টাল ও ভার্টিকাল স্ট্রোক, ঐতিহ্যবাহী পুস্তক ও প্রাতিষ্ঠানিক প্রিন্টিং | LXGW NeoZhiSong, cwTeX Ming, Noto Serif SC/TC |
| **`02_Hei_Modern_Sans`** | **黑体** | ক্লিয়ার, জ্যামিতিক, আধুনিক নো-সেরিফ ও হাই-ডিজিটাল ইউজার ইন্টারফেস | LXGW NeoXiHei, WenQuanYi Zen Hei, Micro Hei |
| **`03_Kai_Calligraphy_Brush`** | **楷体 / 笔草** | ব্রাশ ও হস্তলিপি ক্যালিগ্রাফি, ক্লাসিক্যাল ব্রাশস্ট্রোক ও জীবন্ত ছন্দ | LXGW WenKai, cwTeX Kai, Ma Shan Zheng, Zhi Mang Xing |
| **`04_FangSong_Official_Technical`** | **仿宋体** | অফিশিয়াল রাষ্ট্রীয় দলিল, সিভিল ইঞ্জিনিয়ারিং ও সরকারি টেকনিক্যাল ড্রাফটিং | cwTeX FangSong, FangSong Official Standards |
| **`05_Display_Artistic_Cinema`** | **艺术字 / 创意标题** | সিনেমা পোস্টার, ব্র্যান্ডিং, আধুনিক আর্ট ও রাউন্ডেড কোমল ভিজ্যুয়াল | cwTeX Yen (圆体), jf-openhuninn (粉圆), ZCOOL KuaiLe |
| **`06_Pixel_Retro_Gaming`** | **点阵 / 像素字** | সাইবার রেট্রো গেমিং, ৮-বিট/১০-বিট/১২-বিট ও গেম লোকালাইজেশন | TakWolf Fusion Pixel, Ark Pixel (SC/TC/HK/TW) |

## 🚀 ১-ক্লিক টার্মিনাল ফাস্ট-ইনস্টলার (1-Click Terminal Fast-Installer)

লিনাক্স ও উইন্ডোজ উভয় ওএসে একক টার্মিনাল কমান্ডে পুরো চাইনিজ হানজি আর্কাইভ ইনস্টল করুন:

### 🐧 Linux / macOS:
```bash
curl -fsSL https://raw.githubusercontent.com/mohammadgolamrabbii/typography/main/install.sh | bash -s -- --script chinese
```

### 🪟 Windows PowerShell:
```powershell
irm https://raw.githubusercontent.com/mohammadgolamrabbii/typography/main/install.ps1 | iex
# মেনু থেকে নির্বাচন করুন: 12 (Chinese Hanzi Fonts)
```
